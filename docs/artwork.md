# Example portrait

Alex is a fictional person. The generated portrait is reusable example artwork, not a photograph of the template author or evidence of a real person's qualifications. It depicts an invented product analyst in a navy overshirt against an ivory background.

The source is `public/images/profile/portrait-source.png`. `pnpm dev` and `pnpm build` generate the responsive WebP sizes and social-preview portrait. The About image is a 900-pixel WebP derivative of the same source.

For a replacement, use a square source with clear space around the face and shoulders so it can crop at different sizes. Keep important details away from the edges. Check the homepage, About page and generated sharing image after rebuilding.

Replace the source and About image with your own portrait when customising the template. The other original diagrams and the asset terms are described in [ASSETS.md](../ASSETS.md).
