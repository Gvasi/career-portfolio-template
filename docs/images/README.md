# Repository images

The README screenshots show the fictional demo at
https://career-portfolio-demo.vercel.app, captured on 22 September 2026 from
the v1.0.0 application source.

- `template-home.jpg`: home at 1280 × 800, scroll position zero; the Data story is selected and rotation paused after typing completes.
- `template-mobile.jpg`: the same home at a measured 375 × 812, with no horizontal overflow. This is a browser device emulation, not a physical-device photograph.
- `template-project.jpg`: the This Portfolio overview at 1280 × 800, using the application's supported reduced-motion presentation.
- `social-preview.jpg`: 1280 × 640 repository share card, rendered from `social-preview.html`; the inset is the real home screenshot.

To update the card, edit the adjacent HTML, serve this directory locally, and
capture it at 1280 × 640. Keep the final JPG or PNG under 1 MB for GitHub's
repository social-preview setting. The HTML is an asset source, not an application
page. No application behavior is simulated in these screenshots.
