# Changelog

## 1.0.0

The first template edition.

- Put the original live portfolio beside the template demo and simplify the getting-started guidance.
- Let project rotation and tool-discovery tests follow edited content while preserving interaction checks.
- Add safe request references and execution phases to unexpected API failure diagnostics.

- Bounded simulated availability with shared date validation; unconfigured contact falls back to direct email for preset topics and during mode changes.
- A visible fictional-demo label, working template-source links and hidden example social profiles until the content is personalized.
- Closing animation responds to motion-preference changes and stops when offscreen or the page is hidden.
- Complete clone/setup instructions, explicit EU analytics configuration, focused regression tests and separate CI coverage for development-only submission cases.

- A complete fictional portfolio: Alex Example, career chapters, labelled sample credentials, an illustrated portrait, a sample CV and three project stories.
- Identity in one configuration file; career, home, projects, contact topics and a curated 20-tool catalogue in content files.
- Interactive project overviews and decisions, a stable toolkit explorer with responsive paging, and keyboard and reduced-motion support.
- Optional Google Calendar, Meet and Gmail integrations, protected production forms, and consent-based analytics. Runs without service credentials.
- Separate configuration, OAuth, availability, calendar and delivery modules behind one server API; a React-owned closing invitation with focused animation and measurement hooks; toolkit styles alongside their component.
- A public demo that simulates contact and booking, with no search indexing or real delivery.
- Responsive portraits and a sharing-card portrait generated from one source. A content preflight helps find leftover examples before a personal launch.
- Setup, customisation and practical section/animation reuse guides; architecture, contribution and asset documentation; unit tests, Chromium browser tests and GitHub Actions CI.
